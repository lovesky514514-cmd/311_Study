# 311 背书助手

## 默认模式
- 0 API
- 0 后端
- 0 生成式 AI
- 本地资料搜索
- 错题本
- 背诵挖空
- PWA 缓存

## 可选 AI
顶部打开“AI解释”后，条目才出现“AI解释”按钮。

AI 使用 Puter.js：
- 网站开发者不需要 API Key
- 用户也不需要粘贴 API Key
- 首次使用 AI 时可能要求登录 Puter
- 用户有自己的免费月度额度；用完后是否继续付费由用户自己决定
- AI 关闭时不会加载 Puter.js
- 资料库没有结果时不会调用 AI
- AI 只用于解释已经命中的资料，资料原文和答案仍是唯一依据

## 自检
说明 → 运行网站自检。

会检查：
1. 21 条测试资料是否加载
2. 5 道已核对题答案是否仍为 C/D/C/D/A
3. 典型搜索是否命中正确资料
4. 资料外问题是否被拦截
5. localStorage 是否可用
6. AI 开关逻辑
